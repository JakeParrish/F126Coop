# Team logos

Drop a PNG (transparent background works best) for each team here, named by the
team's slug. They'll show automatically in standings, the roster, and elsewhere.
If a file is missing, a colour badge is shown instead.

Expected filenames:

- `mclaren.png`
- `ferrari.png`
- `mercedes.png`
- `red-bull.png`
- `williams.png`
- `racing-bulls.png`
- `aston-martin.png`
- `haas.png`
- `audi.png`
- `alpine.png`
- `cadillac.png`

(Slug = team name lowercased, spaces → hyphens.)
